# Guess the word
A game where you have to guess a word.

This game is inspired by Taboo but without the word restrictions. It's meant to be played in class in groups, using a mobile phone.

The word lists were created using [Oxford 3000 and 5000](https://www.oxfordlearnersdictionaries.com/wordlists/oxford3000-5000), only keeping nouns, verbs and adjectives.
